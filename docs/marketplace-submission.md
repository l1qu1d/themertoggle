### Maintainer notes

ThemerToggle is one native Omarchy Quattro bar widget. It switches between
remembered light/dark themes using the installed Omarchy CLI and discovers local
preview images. Runtime dependencies are Omarchy Quattro, Quickshell/Qt, and
Python's standard library. No custom installer or keyboard changes are required.
The repository preview uses original demo palette artwork.
